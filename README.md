# 🌍 SceneSense AI: Intel Image Classification using CNN

A deep learning project that classifies real-world images into different scene categories using Convolutional Neural Networks (CNN).

---

##  Overview

This project builds an image classification model using CNN to automatically identify scenes from images. The model is trained on the Intel Image Classification dataset and can classify images into six categories:

- 🏙️ Buildings  
- 🌲 Forest  
- ❄️ Glacier  
- 🏔️ Mountain  
- 🌊 Sea  
- 🚦 Street  

The model learns patterns and features directly from images to perform accurate classification.

---

## 🧠 Model Details

- Model: Convolutional Neural Network (CNN)
- Framework: TensorFlow & Keras
- Image Size: 150 × 150
- Output: Multi-class classification (6 classes)

---

## 📊 Features

✔ Multi-class image classification  
✔ Real-time prediction with confidence score  
✔ Image preprocessing and normalization  
✔ Visualization of predicted results  
✔ Easy to understand and implement  

---

## 📁 Dataset

The project uses the Intel Image Classification dataset.

- Total Images: 25,000+  
- Categories: 6  

⚠️ Dataset is not included in this repository due to size.
